판올림 개인정보처리방침

시행일 2026-10-21 · 적용 대상: 웹사이트 판올림(panollim.com, panollim.kr, 전환 기간 중 jaljaljal-seller-lab.leakim37.chatgpt.site)과 Chrome 확장프로그램 「판올림 · 수집 도우미」

1. 서비스를 위해 저장하는 정보

로그인에서 전달받은 계정 식별자와 이메일, 입력한 활동명, 상품명·스토어명·검색 키워드, 조회 시각과 결과, 일일 사용량, 이용 안내 확인 및 선택 동의 변경 기록을 저장합니다. 다른 회원은 내 상품이나 기록을 볼 수 없습니다. 운영자는 가입·등록·조회 상태의 운영 통계를 확인할 수 있습니다.

2. 선택할 수 있는 데이터 활용

‘기능 사용 및 콘텐츠 관심 분석’에 동의한 경우 상품 등록, 조회 결과, 콘텐츠 클릭 이벤트를 추가로 저장합니다. 동의를 끄면 저장된 선택 분석 이벤트를 삭제합니다. ‘소식 수신’에 동의한 경우에만 운영자의 수신 동의자 목록에 이름과 이메일이 표시됩니다. 두 항목 모두 거절해도 서비스를 이용할 수 있습니다.

3. 외부 서비스에 전달되는 정보

로그인은 ChatGPT의 인증 기능을 이용하고, 웹사이트와 데이터는 OpenAI Sites 및 연결된 Cloudflare 저장소에서 처리됩니다. 순위 조회 시 입력한 검색 키워드를 네이버 쇼핑으로 전송합니다. 이때 회원의 이름과 이메일을 네이버 조회 요청에 포함하지 않습니다. 외부 교육·판매 링크를 열면 해당 사이트의 정책이 적용됩니다.

4. Chrome 확장프로그램 「판올림 · 수집 도우미」

  • 사용자가 시작한 네이버 조사에서 상품명·스토어명·표시 순서와 공개 블로그 ID·블로그명·게시물 제목·주소를 읽고, 사용자가 선택하면 공개 프로필의 인스타그램 연결 후보도 확인합니다.
  • 검색어·수집 조건·진행 상태·중단 위치·결과와, 계정을 구분하는 가명 식별자·장치 식별자는 Chrome 확장 저장소(사용자 브라우저 안)에 보관합니다.
  • 블로그 수집 결과는 로그인한 회원의 판올림 작업으로 전송·저장합니다. 쇼핑 순위 결과는 사용자가 결과 파일을 직접 가져올 때만 서버에 저장합니다.
  • 전체 방문 기록을 수집하지 않으며, 사용자가 요청한 네이버 조사에 필요한 페이지만 읽습니다.
  • 네이버 비밀번호나 로그인 쿠키를 읽거나 서버로 전송하지 않습니다. 네이버 페이지 접속에는 해당 브라우저의 기존 로그인 상태가 적용될 수 있습니다.
  • 확장프로그램은 수집한 정보를 제3자에게 판매하거나 서비스 기능과 무관한 목적으로 사용하지 않습니다.

5. 보관 기간과 삭제

  • 회원이 탈퇴하면 계정 데이터를 즉시 삭제합니다.
  • 1년 동안 서비스를 사용하지 않은 계정의 데이터는 삭제합니다.
  • 내 계정에서 이름과 선택 동의를 변경하거나 전체 데이터를 삭제할 수 있습니다. 블로그·제품 스레드에서 X로 삭제한 저장 메일·수집 결과·상품·브랜드·첨부 자료·저장 글은 목록과 조회에서 바로 숨겨집니다. 함께 숨겨지는 범위는 확인창에서 안내합니다.
  • 삭제 시각부터 30일 안에는 운영자에게 복구를 요청할 수 있으며, 30일이 지나면 복구할 수 없습니다. 기한이 지난 자료와 해당 자료만 사용하는 파일은 서버가 순서대로 정리합니다. 다른 저장 글에서 사용하는 자료는 연결이 정리될 때까지 보관하며, 파일 정리에 실패하면 재시도합니다. 사용량·비용을 보존하기 위한 최소 기록은 원문과 분리해 유지합니다. 다른 기능의 삭제는 각 화면의 안내를 따릅니다.
  • 계정 데이터 삭제는 이 서비스의 데이터에만 적용되며 ChatGPT 계정을 삭제하지 않습니다. 플랫폼의 인프라 로그·백업 보관은 각 제공자의 정책을 따릅니다.
